## 4. RÈGLES DE DÉCISION (J+3 et J+5)

| Situation | Action |
|---|---|
| ≥ 1 vente | Ne touche à rien. Laisse tourner jusqu'à 75 $ |
| 0 vente · CTR > 1,5 % | Le trafic est bon → problème sur la page : change le titre/héros de la landing |
| 0 vente · CTR < 0,8 % | Le créatif ne plaît pas → coupe celui qui a le moins bon CTR, garde le 3 |
| CPA > 8 € | Coupe le créatif concerné, remonte le budget sur le meilleur |
| CPM > 20 € | Publicité trop étroite → élargis l'âge (25-65) ou retire les interests |

**Seuils de référence France (2,97 €)**
- CPM attendu : 8 – 14 €
- CTR attendu : 1,2 – 2,5 %
- CPC attendu : 0,35 – 0,70 €
- CPA cible : **< 5 €** (panier net avec upsell ≈ 5,07 €)
