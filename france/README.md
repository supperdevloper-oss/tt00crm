## 3. كيفاش تنشر اللاندينغ (3 طرق، كلها بالمجان)

### الطريقة 1 — Cloudflare Pages (الأسرع، مجاني، HTTPS أوتوماتيكي)
1. دخل لـ`dash.cloudflare.com` → **Workers & Pages** → **Create** → **Pages** → **Upload assets**.
2. سمّي المشروع `friteuse` وحمّل **محتويات** فولدر `france/` (ماشي الفولدر براسو).
3. كتاخد رابط `friteuse.pages.dev` — HTTPS جاهز فـ30 ثانية.
4. من بعد ربط دومين ديالك (10 $/عام من Namecheap/Cloudflare Registrar).

### الطريقة 2 — Netlify Drop
`app.netlify.com/drop` → جرّ فولدر `france/` → رابط فوري.

### الطريقة 3 — GitHub Pages
دير push لهاد الفولدر فـrepo → Settings → Pages → Branch: main / folder: `/france`.

> ⚠️ **مهم:** شنو ما كانتش الصفحة بـ**HTTPS**، البيكسل ماغاديش يخدم والأمان كيتقصّر.
> الطرق التلاتة كيعطيوك HTTPS بلا فلوس.

## 6. الأرقام اللي خاصك تعرفها (باش ما تتفاجأش)

```
ثمن البيع .........................  9,00 €
عمولة Hotmart (9,9% + 0,50) ....... −1,39 €
الاسترجاع (~8%) ................... −0,59 €
--------------------------------------------
صافي الربح لكل بيعة ............... ≈ 6,80 €
```

**يعني:** إلى كان CPA ديالك فوق 6,80 € → كتخسر فكل بيعة.
فالأسبوع الأول، CPA ديال 8–15 € **عادي** فالسوق الفرنسي. الهدف ماشي الربح، الهدف **البيانات**.
الربح كيجي من: (1) Retargeting، (2) الإيميلات، (3) أبسيل/باكيت بـ19 €.

➡️ **أهم اختبار فهاد الخطة:** من J11، جرّب **14,90 €**. نفس الفانل، نفس الكرياتيف، غير الثمن.
كثير من المرات كيطلع نفس عدد البيعات بثمن أعلى بـ65%.
