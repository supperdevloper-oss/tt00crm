## 3. كيفاش تنشر اللاندينغ (3 طرق، كلهم بالمجان)

### الطريقة 1 — Cloudflare Pages (الأسرع)
1. `dash.cloudflare.com` → **Workers & Pages** → **Create** → **Pages** → **Upload assets**.
2. سمّي المشروع `friteuse` وحمّل **محتويات** فولدر `france/` (ماشي الفولدر براسو).
3. رابط `friteuse.pages.dev` — HTTPS فـ30 ثانية.

### الطريقة 2 — Netlify Drop
`app.netlify.com/drop` → جرّ فولدر `france/` → رابط فوري.

### الطريقة 3 — GitHub Pages
push لهاد الفولدر → Settings → Pages → Branch: main / folder: `/france`.

> ⚠️ بلا **HTTPS** البيكسل ماكيخدمش. الطرق التلاتة كيعطيوك HTTPS بلا فلوس.

## 6. الأرقام (Gumroad — ماشي Hotmart)

```
ثمن البيع .........................  9,00 €  (≈ 10,50 $)
Gumroad 10 % ......................  −1,05 $
رسم ثابت ..........................  −0,50 $
معالجة البطاقة 2,9 % + 0,30 $ .....  −0,60 $
------------------------------------------------
المجموع بالدولار ..................  −2,15 $  ≈ −1,84 €
------------------------------------------------
صافي الربح لكل بيعة ...............  ≈ 7,15 €  (قبل الاسترجاع)
مع 5 % استرجاع ....................  ≈ 6,80 €
```

**يعني:** CPA ديالك خاصو يبقى **تحت 6,80 €**. فوق 7,15 € = كتخسر فكل بيعة.

**3 حوايج خاصك تعرفهم على Gumroad:**
1. **Gumroad هي Merchant of Record** → هي كتخلّص الـTVA الأوروبية. ماعندكش مشكل OSS/TVA ففرنسا.
2. **Discover marketplace** كتاخد **30 %** — ماتفعّلش المنتج فـDiscover فالإطلاق، خليك غير فالرابط ديالك.
3. **الدفع ليك:** الحد الأدنى **100 $**، كل جمعة. من المغرب كاين تحويل بنكي محلي (MAD).
   PayPal Connect **ماشي متاح** لحساب مغربي.

➡️ **أهم اختبار:** من J11 جرّب **14,90 €**. نفس الفانل، نفس الكرياتيف — غير الثمن.
