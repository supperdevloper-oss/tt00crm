## Comment les envoyer

**Option A — à la main (recommandé les 50 premières ventes).**
Gumroad t'envoie un e-mail « New sale ». Tu réponds avec le mail 1 (30 secondes).
À ce volume, le mail personnel est ce qui fait la différence sur les remboursements.

**Option B — Gumroad Workflows.**
`Gumroad → Workflows → New workflow → Purchase` :
- e-mail 1 immédiatement (reprend le texte, en retire les variables)
- e-mail 2 après 1 jour
- e-mail 3 après 3 jours

**Option C — votre outil (Brevo, MailerLite, ConvertKit…).**
Exportez la liste d'acheteurs depuis Gumroad → **Sales → Export** → CSV, puis importez.
⚠️ Ne mettez **jamais** les acheteurs dans la même liste que les prospects : vous perdriez
la distinction acheteur / curieux, qui est toute la valeur de votre liste.

## Les 3 règles qui font baisser les remboursements

1. **Envoyer le mail 1 dans l'heure.** Pas le lendemain. C'est là que le doute s'installe.
2. **Dire quoi faire en premier.** Un acheteur qui a ouvert le PDF ne demande pas de remboursement.
3. **Répondre vite, même mal.** Une réponse courte en 2 h vaut mieux qu'une réponse parfaite en 3 jours.
